## Potential impact

If a log viewer or text export renders an unescaped line break from a route field, one event could appear to be multiple lines and mislead someone investigating an incident. The original logger used structured JSON and Gin supplies a registered route template, not the raw request URL, which limits this risk.

## Review and remediation

The earlier password-fix commit also bounded logged HTTP methods, but CodeQL continued to report `c.FullPath()` in the route field. The middleware now replaces carriage returns and line feeds in that field before sending it to logs, metrics, and traces. Ordinary route templates and unmatched routes are unchanged; the raw URL stays out of the log field. The regression test checks the normalization directly.
